## Requisitos
* Node Version 18.19

## Instalación
```yml
Clonar Repostorio: git clone <project>
Paquetes: npm install | npm i
```

## Generación
```yml
Entornos: ng generate environments
Componentes: ng generate component
Interfaces: ng generate interface
Servicios: ng generate service
```

## Configuración
```yml
JQuery: npm i jquery
Bootstrap: npm i bootstrap
Iconos: npm i bootstrap-icons
Sweet: npm i sweetalert2
Datatables: npm i datatables.net-bs5
Bootratp: npm i --save-dev @types/bootstrap
```
